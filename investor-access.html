УРОВНИ ДОСТУПА

L0 → L3

Public teaser → screened materials → NDA Data Room → Deal Room. Уровень доступа определяется стадией переговоров и перечнем раскрываемой информации.

КОНФИДЕНЦИАЛЬНОСТЬ

Private documents stay private

GitHub Pages не используется для хранения персональных, коммерчески чувствительных или конфиденциальных документов. Для этого требуется отдельный защищённый backend/auth-контур.

STATUS

Публичный Investor Room на этом сайте — демонстрация интерфейса, структуры допуска и контроля. Реальный персональный кабинет должен иметь серверную авторизацию, журнал доступа, разграничение прав и защищённое хранилище документов.
